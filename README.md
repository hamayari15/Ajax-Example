# 📰 News Headlines

[![Powered by NewsAPI](https://img.shields.io/badge/Powered%20by-NewsAPI.org-blue)](https://newsapi.org)

A news headlines app built with vanilla JavaScript, Bootstrap 5 and XMLHttpRequest. Filter top stories by country and category using NewsAPI.

![Screenshot](screenshot.png)

## Features

- Browse headlines by country and category
- Read the news in English, French or Arabic, with right-to-left support
- Load more articles with one click
- Skeleton loading cards while news is loading
- Smart fallback when a country has no top headlines
- Works on desktop and mobile
